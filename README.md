# iamscientist.ai — Landing Page Clone

## Live Demo
[https://iamscientist-clone-tau.vercel.app]
## Tech Stack
- **React 18** with Vite
- **Tailwind CSS** for styling
- **Swiper.js** for carousels
- **react-icons** for icons
- Google Fonts (Inter, Poppins)

## Getting Started

```bash
npm install
npm run dev
```

## Build for Production

```bash
npm run build
npm run preview
```

## Features Implemented
- [x] Responsive Navbar with all links + Enroll & Login buttons
- [x] Hero Slider with 2 auto-rotating slides
- [x] Contest Schedule with 3 tabs (General, Contest, Course) + Countdown timer
- [x] 3 Course cards with images, meta, and CTA
- [x] Partner logos in infinite scrolling marquee
- [x] Gold, Silver, Bronze medal prize cards
- [x] Merit Awards text block
- [x] Photo carousel (7 images) with Swiper.js
- [x] FAQ accordion (5 items, toggle working)
- [x] Image gallery (5 containers) with masonry grid
- [x] Newsletter email subscribe UI
- [x] Footer with 4 columns + social links
- [x] WhatsApp floating button
- [x] Fully responsive (mobile, tablet, desktop)
- [x] Smooth scrolling enabled
- [x] Hover effects on buttons, cards, links
- [x] Scroll-reveal animations with IntersectionObserver
